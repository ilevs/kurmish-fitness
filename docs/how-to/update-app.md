# Обновить приложение

1. Открой ту же ссылку: [kurmish-fitness.apk](https://github.com/ilevs/kurmish-fitness/releases/download/latest/kurmish-fitness.apk). По ней всегда лежит последняя сборка.
2. Установи поверх. Журнал и профиль сохранятся: сборки подписаны одним ключом.

Не удаляй приложение перед установкой: вместе с ним удалится журнал.
