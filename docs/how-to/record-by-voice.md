# Записать тренировку голосом без интернета

Распознавание речи встроено в приложение и работает без сервисов Google. Интернет нужен один раз: при первой голосовой записи приложение скачивает модель распознавания (около 225 МБ, лучше через Wi-Fi). Дальше всё работает без сети.

1. Открой «Дневник»: поле записи с кнопкой «Сказать» наверху.
2. В первый раз разреши доступ к микрофону и дождись, пока скачается модель: прогресс виден под кнопкой. Каждый раз после открытия вкладки модель пару секунд загружается в память.
3. Когда появится «Слушаю», говори подряд, упражнение за упражнением: «присед сто сорок на три по два, потом жим стоя пятьдесят на пять». После каждой короткой паузы сказанная фраза дописывается в поле.
4. Нажми «Стоп».
5. Проверь блок «Распознано». Если что-то не так, поправь текст в поле руками. Можно нажать «Сказать» ещё раз: новые фразы допишутся в конец.
6. Нажми «Сохранить».

Если доступ к микрофону запрещён, разреши его: «Настройки → Приложения → Курмыш Фитнес → Разрешения → Микрофон».

Для озвучки советов нужен русский голос синтеза речи: «Настройки → Специальные возможности → Синтез речи → Установить голосовые данные → Русский». Названия пунктов зависят от телефона.

Чтобы записать вчерашнюю тренировку, начни со слова «вчера». Чтобы тренер учёл самочувствие, добавь «было легко» или «было тяжело».
