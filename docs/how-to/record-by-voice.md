# Записать тренировку голосом без интернета

1. Один раз скачай русский язык для офлайн-распознавания: «Настройки → Система → Язык и ввод → Голосовой ввод Google → Распознавание речи офлайн → Русский». Названия пунктов зависят от телефона.
2. Для озвучки советов скачай русский голос: «Настройки → Специальные возможности → Синтез речи → Google → Установить голосовые данные → Русский».
3. Открой вкладку «Записать» и нажми «Сказать».
4. Говори подряд, упражнение за упражнением: «присед сто сорок на три по два, потом жим стоя пятьдесят на пять».
5. Проверь блок «Распознано». Если что-то не так, поправь текст в поле руками. Можно нажать «Сказать» ещё раз: новая фраза допишется в конец.
6. Нажми «Сохранить».

Если вместо распознавания появилось сообщение, что его нет, установи приложение «Google» или любую клавиатуру с голосовым вводом и вводи голосом прямо в поле.

Чтобы записать вчерашнюю тренировку, начни со слова «вчера». Чтобы тренер учёл самочувствие, добавь «было легко» или «было тяжело».
