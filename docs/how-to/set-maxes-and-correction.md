# Ввести ПМ и процент корректировки

## ПМ

1. Открой «Профиль» и найди поля «ПМ: присед, кг», «ПМ: жим лёжа, кг», «ПМ: становая тяга, кг», «ПМ: жим стоя, кг».
2. Серым в пустом поле показана оценка по журналу за последние 60 дней.
3. Введи реальный максимум или близкий к нему. Не завышай: с завышенным ПМ цикл работает хуже.
4. Чтобы вернуться к оценке по журналу, очисти поле.

Если журнал показывает максимум заметно выше введённого, на вкладке «Сегодня» появится подсказка.

## Процент корректировки

Это прирост расчётного ПМ от недели к неделе.

1. Введи значение в поле «Процент корректировки». Для натурального атлета обычно 0,5–1 %.
2. Если тренировки идут слишком легко, подними на 2 %, но не выше предела цикла (например, 2,5 % для СРЦ15 и СРЦ16, 1,5 % для СРЦ14).
3. Если слишком тяжело, поставь 0 %.

Тренер сам подскажет это на вкладке «Сегодня», если в записи было «легко» или «тяжело».
