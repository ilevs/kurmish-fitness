# Таблицы разминки

Источник: `WarmUp` в `app/src/main/java/com/kurmish/fitness/core/WarmUp.kt`. Подводящие подходы считаются от первого рабочего веса. «Гриф» — пустой гриф 20 кг, остальное — доля рабочего веса, округлённая до 2,5 кг. Запись «3×5» — 3 подхода по 5 повторов. Подходы не тяжелее рабочего веса отбрасываются.

Жим стоя, жим средним и узким хватом разминаются по таблице жима лёжа. Для подсобных упражнений таблиц нет.
