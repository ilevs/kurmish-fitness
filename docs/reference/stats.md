# Статистика

Все показатели считаются из Дневника на устройстве (`core/Stats.kt`). Неделя начинается с понедельника.

## Сводка

| Показатель | Как считается |
|---|---|
| Тренировок | Записи Дневника за последние 28 дней, включая сегодня |
| В неделю | Тренировок за 28 дней × 7 / 28 |
| Тоннаж | Сумма [тоннажа](load-metrics.md) тренировок за 28 дней |
| Последняя тренировка | Сколько дней прошло после самой поздней записи не позже сегодняшнего дня |

## Динамика ПМ

Для каждого дня, когда упражнение делали с весом, берётся лучшая оценка разового максимума по формуле Эпли: вес × (1 + повторы / 30). Подходы больше 10 повторов не учитываются, одиночный подход даёт ровно свой вес. Ось времени пропорциональна датам, поэтому пропуски в тренировках видны как длинные отрезки.

Изменение над графиком: последняя точка минус первая.

## Нагрузка по неделям

Последние 12 недель, включая текущую. Недели без тренировок показываются пустыми.

| Показатель | Как считается |
|---|---|
| Тоннаж | Сумма тоннажа тренировок недели |
| КПШ | Сумма повторов всех подходов недели |
| Интенсивность | Средний % от ПМ тренировок недели, взвешенный по их КПШ. Учитываются только тренировки, где ПМ известен хотя бы для одного упражнения. ПМ берётся действующий: введённый в Профиле или оценка по Дневнику |
| Тренировки | Число записей за неделю |

## КПШ по зонам

Источник: `LiftZones` в `core/LiftZones.kt`. Для последней тренировки подходы каждого упражнения с известным ПМ раскладываются по зонам интенсивности, подъёмы в зоне сравниваются с коридором, который даёт результат без отказа. Подходы легче 55 % ПМ и упражнения в гравитроне не считаются. Строки вне коридора выделены цветом.

| Зона, % ПМ | Коридор КПШ за тренировку | Оптимум |
|---|---|---|
| 55–70 | 18–30 | 24 |
| 70–80 | 12–24 | 18 |
| 80–90 | 10–20 | 15 |
| от 90 | 4–10 | 7 |

В плане на сегодня по своему циклу у упражнения появляется пояснение «КПШ …», если запланированные подъёмы в какой-то зоне выходят из коридора. У встроенных программ проверки нет: их объём задан методикой.

## Баланс движений

Повторы всех подходов за последние 28 дней, сгруппированные по типу движения (тип каждого упражнения — в [базе упражнений](exercises.md)). Упражнения, которые не удалось узнать, не учитываются. Подъёмы на носки в присед не идут: на баланс плоскостей они почти не влияют.

Противоположные движения уравнивают по числу повторов. Перекос в сторону второго в паре допустим и даже полезен: он бережёт плечи, колени и спину.

| Пара | Совет появляется, когда |
|---|---|
| Жим от груди — тяга к поясу | жимов от груди в 1,5 раза больше, чем тяг к поясу |
| Подтягивания — жим вверх, брусья | подтягиваний в 1,5 раза больше, чем жимов вверх |
| Присед — тяги с пола, наклоны | приседа в 1,5 раза больше, чем тяг и наклонов |

Ещё советы появляются, когда в паре одна сторона есть, а другой нет совсем; когда есть жимы или тяги, но нет вращения плеча наружу; когда нет ни одного упражнения на пресс и кор. Если советов нет, под полосками написано, что плоскости в равновесии.
