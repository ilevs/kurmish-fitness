# Формат записи тренировки

Разбор делает `WorkoutParser` (`app/src/main/java/com/kurmish/fitness/core/WorkoutParser.kt`). Он работает без сети и одинаково понимает набранный текст и распознанную речь.

## Подготовка текста

- Регистр не важен, «ё» равна «е».
- Числа словами переводятся в цифры: «сто двадцать два с половиной» → 122.5.
- Десятичная запятая между цифрами: «62,5» → 62.5.
- Знаки умножения `x`, `х`, `×`, `*` между числами равнозначны.

## Упражнения

Новое упражнение начинается с его названия. Слова сравниваются по основе, поэтому «приседания», «присед» и «приседал» означают одно и то же. Если подходит несколько названий, побеждает самое длинное: «тяга в наклоне» не путается со становой «тягой».

| Упражнение | Как можно назвать | Собственный вес |
|---|---|---|
| Присед | присед, приседания | нет |
| Жим лёжа | жим, жим лёжа, жим штанги лёжа | нет |
| Становая тяга | становая, тяга, тяга классика, тяга сумо | нет |
| Жим стоя | жим стоя, армейский жим, жим над головой | нет |
| Жим средним хватом | жим средним хватом, средний хват | нет |
| Жим узким хватом | жим узким хватом, узкий жим | нет |
| Жим гантелей | жим гантелей, гантели | нет |
| Французский жим | французский жим, французский | нет |
| Подъём на бицепс | подъём на бицепс, бицепс | нет |
| Тяга на прямых ногах | тяга на прямых ногах, румынская тяга, мёртвая тяга | нет |
| Тяга в наклоне | тяга в наклоне, тяга штанги в наклоне | нет |
| Подтягивания | подтягивания | да |
| Брусья | брусья, отжимания на брусьях | да |
| Отжимания | отжимания | да |
| Пресс | пресс, скручивания | да |
| Гиперэкстензия | гиперэкстензия, гиперы | да |

Незнакомое название перед числами сохраняется как есть: «махи 10 на 15» станет упражнением «Махи».

## Подходы

Числа, связанные `x`, «на», «по» или единицами, образуют одну строку подходов. Запятая или точка заканчивают строку.

Если у числа есть единица, роль задаёт она:

| Слова после числа | Роль |
|---|---|
| кг, килограмм, кило | вес |
| раз, повтор, повторений | повторы |
| подход, подхода, сет, серии | подходы |

Числу после «с», «со», «весом» достаётся роль веса: «3 подхода по 3 с весом 180».

Числа без единиц раскладываются по позиции:

| Запись | Упражнение со штангой | Собственный вес |
|---|---|---|
| `100` | вес 100, 1 повтор | 100 повторов |
| `100 на 5`, `100x5` | 100 кг × 5 | 100 кг доп. веса × 5 (только с «на») |
| `3 по 10` (первое число меньше 20) | 3 подхода × 10 | 3 подхода × 10 |
| `100 по 5` (первое число от 20) | 100 кг × 5 | отбрасывается: 100 подходов |
| `4x12` | 4 кг × 12 | 4 подхода × 12 |
| `100 на 5 по 3`, `100x5x3` | 100 кг × 5 повторов × 3 подхода | то же |

«…, 3 подхода» сразу после строки подходов уточняет число подходов этой строки: «жим 100 на 5, 3 подхода» → 100 кг × 5 × 3.

Несколько строк подряд: «жим 60x10, 80x5, 100x3x3».

Строка отбрасывается, если повторов нет или больше 100, подходов больше 20 или вес больше 500 кг.

## Дата и самочувствие

| Слово | Что меняется |
|---|---|
| вчера | дата на день раньше |
| позавчера | дата на два дня раньше |
| тяжело, тяжко, еле, трудно, сложно, не дожал, провал, устал, «не легко» | самочувствие «тяжело» |
| легко, свободно, просто, изи | самочувствие «легко» |
