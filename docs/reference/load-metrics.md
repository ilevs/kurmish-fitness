# Показатели нагрузки

Источник: `LoadCalculator` в `app/src/main/java/com/kurmish/fitness/core/Load.kt`. Формулы повторяют тренировочный дневник в формате Excel. Показатели видны под каждой записью дневника.

| Показатель | Как считается |
|---|---|
| Тоннаж | Σ вес × повторы × подходы; для упражнений с собственным весом вес считается за 1 |
| КПШ | количество подъёмов штанги: Σ повторы × подходы |
| Средний вес | тоннаж / КПШ |
| Интенсивность | средний % от ПМ, взвешенный по повторам; % каждого подхода округляется до целого |
| Нагрузка с коэффициентами | Σ вес × повторы × подходы × коэффициент зоны × коэффициент воздействия |
| Время | Σ подходы × коэффициент зоны × минуты на подход + 30 минут |

## Время на подход

| % от ПМ | Множитель |
|---|---|
| меньше 45 | 0,5 |
| 45–54 | 0,8 |
| 55–64 | 0,9 |
| 65–74 | 1,0 |
| 75–84 | 1,1 |
| 85 и больше | 1,2 |

Минуты на подход зависят от коэффициента воздействия упражнения: от 0,8 — 6 минут, до 0,4 — 1,5 минуты, между ними — 3 минуты.

## Коэффициент воздействия упражнения

| Коэффициент | Упражнения |
|---|---|
| 1,0 | присед, жим лёжа, становая тяга |
| 0,6 | другие многосуставные: жим стоя, жимы разным хватом, жим гантелей, тяги, подтягивания, брусья; незнакомые упражнения |
| 0,3 | односуставные и с собственным весом: французский жим, бицепс, отжимания, пресс, гиперэкстензия |
